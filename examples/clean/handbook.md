# Platform handbook

## Terms this handbook uses

- **artifact**: A file produced by a build and stored for later use.
- **token**: A short-lived credential that authorises an API request.
- **charge**: An amount of money billed to a customer account.

Whole terms only. The discouraged spelling `artefact` appears here inside a code
span, and the words artefacts and build-artefact appear in prose; none of the
three is an occurrence of the discouraged alias, so none of them is reported.

```text
artefact
```
